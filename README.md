# Enhanced+

**Enhanced+** is a [MelonLoader](https://melonwiki.xyz/) mod that introduces small quality-of-life improvements and returning back some character customization.

**Required version of MelonLoader: 0.7.3.**

## Features

- **FPS Counter** — Displays the current frames per second (FPS) with color-coded performance indicators.
- **Ping Counter** — Shows your current ping.
- **Host Indicator** — Identifies the host in player list.
- **Unused Hats** — Returns "unused hats" in character customization at no cost.
- **Quick Menu Return** — Allows you to return to the main menu using a keyboard shortcut.

## Controls

| Key | Action |
|:---:|---|
| `F9` | Return to the main menu |
| `F10` | Toggle the FPS and ping display |
